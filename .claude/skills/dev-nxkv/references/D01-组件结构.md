# D01 · web 端组件结构：有哪些件、各自负责什么

> D 序列 · web 端之一。回答「前端有哪些组件、各自管什么、改 UI 该动哪个文件」。
> 页面 ↔ 组件 ↔ API 的对应关系见 [[D02-页面与组件关系]]；后端侧见 [[C01-serve端]]。

## 1. 应用壳：Provider 组装

```text
main.tsx
  └─ <StrictMode>
       └─ <StoreProvider>       store.tsx      全局 UI 状态（bootstrap + 持久化的「选择」）
            └─ <ToastProvider>   components/toast/  页内轻提示
                 └─ <App />       App.tsx       应用壳 v2：FlexLayout 工作区 + hash 路由
```

- **没有顶栏**：全局动作（重置布局 / 设置）全部集中在侧边栏头部——侧边栏是工作区里的一块面板，可拖拽可浮出，动作跟着它走。
- **面板是一等公民**：目录、目录工作台、项目组、仓库管理、云端总览……都是工作区里的一块面板，可拖拽、可拆分、可拖出成浮窗；布局存 localStorage，重开还在。
- 路由与「选中的面板」**互为镜像**：
  - 路由变化 → 打开/聚焦对应面板；
  - 选中面板变化 → 地址跟着走（`history.replaceState`，不触发 hashchange）。
  - 所以**深链 = 一屏**：把地址发给别人，对方看到的布局与你一致。

## 2. 关键文件

| 文件 | 职责 | 关键点 |
|---|---|---|
| `App.tsx` | 应用壳：hash 路由解析、工作区模型、面板 ↔ 路由同步、轮询 | 路由用 `hash`：`#/dir/<key>`、`#/global`、`#/overview`、`#/group/<id>`、`#/doc?ref=…`、`#/templates/…`、`#/cloud`、`#/repos` |
| `app-context.tsx` | 运行时上下文（`useApp()`） | 提供 `rows`（队列）、`repoData`（仓库/看板）、`prefs`、`model`、`route`、`openPage`、`closePanel`、`shell`、`refreshLocal`、`refreshRepos`、`tpl` |
| `store.tsx` | 全局 UI 状态 | 只持久化「**选择**」（当前视图、主题筛选、多选勾选），**不持久化数据**——数据永远从 `/api` 拉；当前工作空间刻意**不**存 localStorage（真相源是 `config.json`，存两份就会「面板显示 A 组、实际写进 B 组」） |
| `api/client.ts` | API 客户端 | `api(path, {method, body, timeoutMs})`；响应包 `{ ok, data }` / `{ ok, error, code }`；失败抛 `Error` 且带 `.code` / `.details`；默认超时 30s |
| `api/client.generated.ts` | **codegen 产物**：typed client | 从 action 类反推入参/出参类型（type-only 引后端 schema，编译期擦除）；**不在前端做 zod 运行时校验**（省掉浏览器包里整个 zod）；改了 action 声明要重跑 `pnpm gen` |
| `routes/index.ts` | 路由页总表 | `PAGES` + 正反两向查表（`pageOfView` / `REVERSES`）；加一个页面 = `routes/<名>.ts` 写一份 `definePage` + 这里加一行 |
| `route-map.ts` | 路由 ↔ 面板的纯映射外壳 | **不引 React**（单测直接 import）；具体规则在 `routes/<名>.ts`，本文件只把 node/route 归一成查表入参、把结果拼成 `PanelSpec` |

### 路由声明：`routes/<名>.ts` 的 definePage 约定

每个视图一份声明（`routes/dir.ts` / `doc.ts` / `doc-ref.ts` / `group.ts` / `static.ts` / `templates.ts` / `keys.ts` / `types.ts`）：

- 正向 `panelOf(route, ctx)`：hash → 打开哪块面板、页签名是什么；
- 反向 `reverse[]`：面板 config → 写回 hash 的格式化器，**按 `order` 升序尝试，第一个给出非 undefined 的赢**——`page` 面板同时被 dir 与 group 写回，组锚定页更具体所以 `order` 更小；同 `order` 按登记顺序。
- 「加一个页面」不再改 `route-map.ts`；恒等式（两个方向必须逐字互逆）由 `tests/unit/route-table.test.mjs` 用基线夹具钉住。

### 路由 ↔ 面板的恒等式（踩过坑）

`panelSpecOfRoute` 生成的 config 必须能从 `routeOfPanel` 写回的路由**逐字**复现——`openPanel` 按 `component + config` 去重，任何一边多一个字段都会裂出重复页签。

- 文档 `docId` 带 `rel:` / `path:` 前缀冒号，**整串 encode 会把 `:` 变成 `%3A`** → 只编码冒号后的路径段，前缀原样保留（`routes/doc-ref.ts`，唯一真源，`route-map.ts` 只转出口）。
- 返回值是「已编码」的查询串片段——交给 `URLSearchParams` 会**二次编码**（`/` → `%2F` → `%252F`）。所以两个方向都在 `routes/` 内完成 encode/decode，调用方只做字符串拼接。
- 旁路面板（`cfg.beside`，评论任务右侧）写回时返回 `null` 不改地址——否则路由 effect 会按原文重开主区，冲掉评论页。

## 4. 页面的 API 收口：`page/<name>/api.ts`

**页面组件（含页面私有组件）不许出现 `api()` 裸调用**——所有 `/api` 请求都从本页 `api.ts`
的具名函数走（#176 模板约定）。eslint 强制：`page/**` 全部目录受 `no-restricted-syntax` 拦截，
`api.ts` 自身豁免；tests 的 grep 对账互为备份（lint 拦写法，测试拦存量）。

- `api.ts` 只搬调用不改语义：路径 / 方法 / body 与裸调时逐字一致；顺带补 TS 返回类型。
- 改某个接口的调用 → 先看本页 `api.ts` 有没有；没有就**加函数**，不要在组件里直接 `api()`。
- 已收口的 10 页：cloud / dag / dir / doc / group / overview / progress / refs / repos / settings。
  `page/templates/` 没有自己的 `api.ts`（该页是纯编辑器面板，不发请求）。
- 共享件（`components/`）的调用不受这条约束，但同样建议走就近收口层。

## 9. 前端三条硬约束

1. **只调 `/api/*`**；禁止 import 后端模块，只能用 `src/shared/` 的纯函数（`eslint.config.js` 会拦；`client.generated.ts` 的 type-only 引用是唯一豁免）。
2. **漏 import 由 typecheck 抓**：前端全部 TS/TSX、strict 全开后，漏 import 是 `Cannot find name`，`pnpm typecheck` 直接红——比 lint 更早也更准（`no-undef` 已对 TS 关闭，避免误报 DOM 类型名）。
3. **页面 API 收口到本页 `api.ts`**（§4）；共享展示逻辑放 `modules/`，页面组件放 `page/<name>/`；大组件按职责拆兄弟文件（行数门禁见 [[B01-架构分层]] §7）。

## 10. 侧栏三态（`components/sidebar/side-state.ts`）

| 状态 | weight | 约合宽度 @1440 |
|---|---|---|
| `expanded` | 16 | ≈ 229px |
| `collapsed` | 2.5 | ≈ 41px（整条可点展开） |
| `closed` | 1.2 | ≈ 20px（左缘只剩半圆弧把手） |

判定阈值（读回存量布局时按 weight 分档）：`< 2` → closed；`2 ~ 8` → collapsed；`≥ 8` → expanded。

**收起宽度是 tabset weight 的百分比，不是绝对像素**——旧实现拿「绝对像素 < 46」当判定，而 2.5% 在宽窗口下折算出来比 46px 还宽，判定永远不翻转，侧栏卡在「压窄的展开态」。现在：点击收起/展开/关闭直接翻状态并落模型；拖拽走**迟滞带**（< 46px 收起，≥ 120px 展开，中间保持现状防抖）；关闭态例外（只有 ≥ 120px 才翻回展开）。

## 11. 前端改动的验证要点

- **浏览器缓存会让「改了不生效」**：验证前用 `?cb=1` cache-buster，并重启 serve。
- 面板是构建产物：`src/web/public` 是 gitignore 的 vite 输出，改前端要 `pnpm build`。
- 端到端实测可用 `nx-kv-panel-probe` skill（独立 store 播种 + 临时端口 serve + Playwright 探针，**绝不碰用户真实队列数据**）。
- 工作区可能有多会话并行改前端文件：**提交前 `git status` 核对，只 `git add` 自己的文件清单，绝不 `git add -A`**。
