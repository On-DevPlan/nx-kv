- tables: `tasks`（`topic_id` → `repo_topic_id`，新增 `group_topic_id`，丢弃 `repo_key`）

- changes:
  - **任务归属变成两条 topic 外键**：`repo_topic_id`（必填，仓库队列——编号序列与
    `get --cwd` 领取按它，与改造前完全一致）、`group_topic_id`（可空，组归属唯一来源）。
  - **组本身成为一条 topic**：key = `group:<组key>`，cwd 空，repo_key 指向组行；
    组页 `WHERE group_topic_id = ?` 一次查完（走 `ix_tasks_group`），不再扫描正文。
  - v16 拆出来的 `(cwd, group_key)` 队列在本步被吸收：任务搬回同 cwd 的仓库队列
    （seq 冲突顺延），组队列换成组 topic，旧行删除。
  - `repo_key` 列丢弃：仓库归属统一由 repo_topic 表达（用户口径「cwd-repo 就是
    repo 的 key，指代能从哪个路径获得」——读取走 `topics.repo_key`，写入走关联）。
  - 为什么拆成 v16 + v17：v16 已在本机库应用（user_version=16），迁移不可变；
    结构修正在 v17 承接，历史步骤保持原样。
