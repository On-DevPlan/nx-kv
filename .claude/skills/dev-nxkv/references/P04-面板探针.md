# P04 · 原语 · 面板探针（隔离实测）

> 被 `R01-加一种资源类型.md`、`R03-改面板交互.md`、`R04-加面板页面.md`、`R07-排障与定位.md` 引用。
> 面板行为的唯一可靠证据：独立数据目录 + 临时端口 + Playwright（`channel:'chrome'`），绝不碰真实队列。

## ① 前置：隔离决定一切

| 要隔离什么 | 怎么做 |
|---|---|
| 整个 home（**推荐**） | `$env:NX_KV_HOME` 指向 `temp/` 下目录——库、repos.json、附件全隔离 |
| 只隔离任务队列 | `NX_KV_LOCALTASK_STORE` 指向 `temp/`——**坑：只隔离任务**，repos/boards 仍写真实 store |
| 端口 | `--port 7878/7879`，别撞用户的 serve |
| 种子数据 | 脚本写进隔离 store；**种子文件带 BOM 会解析成空 store**（写文件用无 BOM UTF-8）；看板成员字段存的是 repoKeys 不是路径 |

```powershell
$env:NX_KV_HOME="<repo>/temp/home-probe"
node bin/kv.mjs serve --port 7879 --no-open
```

## ② 动作：探针骨架与坑位表

探针脚本放 `temp/probe-<任务号>.mjs`（git 不入库）；`page.on('pageerror')` 必收；
断言逐场景给明确输出，不是「看起来对」。每一条坑位都真实踩过：

| 症状 | 处置 |
|---|---|
| 菜单项点不动（30s 超时） | 元素是 `<button role="menuitem">` 且 portal 到 body → `dispatchEvent('click')` 直接派发，React 合成事件照常触发 |
| `page.fill()` 改不了 contentEditable | `click` → `Control+A` → `keyboard.type`（值只在 DOM 变了，React 没收到 onChange） |
| 探针结果读不全 | 页面内先 `JSON.stringify` 成单行再输出，或写文件再读（一次 `console.log` 打对象被截断） |
| 同页多个 `.mdw` 抓错块 | 断言全量扫描而非取第一个；逐场景清 `localStorage('nx-kv-ui.workspace')` 并 **reload**（同页改 hash 不重载） |
| 改了代码看不出变化 | `pnpm build` + 重启 serve + URL 带 `?cb=1`（浏览器缓存不判新旧；改 action 必重启 serve） |
| 探针把真实 repos.json 写脏 | 只设了 `NX_KV_LOCALTASK_STORE`——换 `NX_KV_HOME` 整目录隔离 |
| toast 断言不稳定 | 同文案原地续时不压新节点（栈上限 3 条）；断言取「最后一条」 |
| bash heredoc 写探针丢反斜杠 | heredoc 吃 `\`——路径写正斜杠，或把脚本写成文件再执行 |
| 临时产物进了 lint / git | 探针与种子都放 `temp/`；别把产物散进 src/tests，更别 `git add` 它们 |

## ③ 自检

| 检查 | 判据 |
|---|---|
| 零 pageerror | `pageerror` 收集为空 |
| 断言全过 | 每个场景有明确断言输出与关键值 |
| 真实队列无损 | `node bin/kv.mjs db status` 显示的库路径仍是隔离目录 |
| 截图留证 | 关键状态截图，供人工复核 |

## ④ 失败分支

| 症状 | 原因 | 处置 |
|---|---|---|
| 连接被拒 | serve 没起 / 端口不对 | 看启动日志；换 `--port` |
| 行为时对时错 | 浏览器缓存混了新旧 bundle | `?cb=1` + 重启 serve；确认访问的是新进程 |
| 探针报元素不可见 | 断言取了隐藏元素 | 等 `visible`，或先滚动到位 |
| 隔离目录里报「表不存在」 | 种子没写入 / BOM 吃掉了种子 | 检查种子文件编码与 store 路径 |

## ⑤ 反模式

- 在用户的真实库/真实队列上验面板行为（一次误点就是脏数据）。
- 只截图不断言（截图证明不了行为）。
- 探针脚本写进 `src/` 或 `tests/`（会进 lint 与 git）。
