# Intent: Agent 桌面式 MD 任务工作台

## 背景与动机

现有 nx-kv 面板以看板/卡片为主；用户希望优化为更接近各类 Agent 桌面端的交互：目录导航 + 单输入框发任务，并用 Markdown 作为可预览、可划选追加的任务载体。

## 目标

- 右侧侧边栏承载目录树
- 点开目录时，主区只有一个任务输入框（发送即提交）
- 支持导入 MD：作为目录下的子页面 / 任务文档，可预览
- 任务未完成或对 MD 某段有问题时，预览区划选 → 下拉动作（如「此区域有问题 / 追加任务」）

## 约束与边界

- 本轮产出是**原型设计**（可点击 HTML + 设计文档），不改业务源码
- 视觉延续既有暖中性纸感（见 `docs/research/VISUAL-SPEC.md` / `plan/uiux-redesign.html`），不做紫渐变 SaaS 风
- 侧栏在**右侧**（与当前 v2 左栏不同）

## 关键决策

| 决策点 | 结论 | 理由 |
|--------|------|------|
| 侧栏位置 | 右侧 | 用户明确要求；主区左侧留给预览/输入焦点 |
| 目录态主区 | 仅 composer | 对标 Agent 桌面端「说一句话就开工」 |
| MD 角色 | 任务文档 + 子页 | 导入即任务，不是附件 |
| 划选菜单 | 追加/标注问题 | 未完成任务的增量反馈入口 |

## 待定问题

- 追加任务是挂到原 MD 的子任务，还是目录下新建一条？
- 划选锚点是否需要持久化行号/段落哈希？
- 文字任务与 MD 任务在侧栏如何区分图标？
