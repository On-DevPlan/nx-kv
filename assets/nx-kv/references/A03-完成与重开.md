# A03 · 完成与重开

## 三步

1. 干完 → `localtask done --id N --summary "…"`（summary 必须写：它是下一轮唯一的上文）。
2. 若返回 `blocked / goal_not_reached`（时间目标未到）→ **不要硬标**，派 sub agent 重提需求，
   等 `timegoal check` 的 `reached:true` 再 done。
3. 用户提修改意见 → `localtask reopen --id N --text "…"` 就地回写，**不要新开一条**。

## 标完成

```bash
nx-kv localtask done --id <n> --summary "改了什么 / 关键决策 / 遗留问题" --json
```

`--summary` 就是**下一轮 agent 能看到的「上轮做了什么」**：写清改了哪些文件、为什么这么改、
还剩什么。不要写「已完成」「搞定了」。

## 被拒：时间目标未到

带时间目标的任务（`add --duration`）到点前 `done` 会返回业务结果（不是错误）：

```json
{ "status":"blocked", "reason":"goal_not_reached", "remainingSec":1830,
  "hint":"时间未到，不能标记完成——请派出 sub agent 重新提出新的需求；到点后…再来标完成" }
```

处理：**不要**硬标、**不要**自己改时间 → 派 sub agent 重提需求继续推进；
`timegoal check` 返回 `reached:true` 后再 `done`。详见 [[A04-阻塞等待与时间目标]]。

## 按反馈重开（就地回写同一条）

```bash
nx-kv localtask reopen --id <n> --text "<改后的正文>" [--kind reopen|comment] --json
nx-kv localtask chain  --id <n> --json      # 查链：origin / reopen / comment / current
```

- 正文替换成 `--text`，上一轮总结压进 `history[]`；
- 已完成的任务清掉领取/完成标记回到 `pending`（再 `get` 一次即可继续）；
- 未完成的任务只改正文 + 记链。
- `--text` 省略 = 只重开不改正文（例如用户只是说「再来一轮」）。

## 偏差

| 偏差 | 正确做法 |
| --- | --- |
| 用户提修改意见就新开一条任务 | `reopen` 原任务（同号），否则链断了、历史也丢了 |
| `done` 不写 summary | 必须写：它是下一轮唯一的「上文」 |
| 被 `blocked` 后硬改时间/绕过 | 按 hint 派 sub agent 重提需求 |
