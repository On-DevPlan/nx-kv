- changes:
  - **任务归属从正文 frontmatter 搬进库内关联**。`tasks` 直接持两个 topic 外键：
    `repo_topic_id`（必填，仓库队列——编号序列与 `get --cwd` 领取按它，行为与改造前一致）、
    `group_topic_id`（可空，组队列——组归属的唯一来源）。

    `WHERE group_topic_id = ?` 一次查完（走 `ix_tasks_group`），不再全量拉任务 + 逐条解析正文。
  - **删除哨兵仓库 `__unbound__`**：队列必须绑真实仓库。老库升级时按 cwd 匹配已登记仓库，
    匹配不到就自动登记 `local/<目录名>`（**绝不因为「找不到归属」丢任务**）；导入同一个口径。
  - 正文只留 markdown（标题 + 内容）：迁移时解析旧 frontmatter 的 `board`/`project` 落到
    关联里，然后剥掉 `---` 头。之后提交/编辑都不再写 frontmatter。
  - 为什么重建：SQLite 不能改列名、不能加带外键的列；按 v9 的 12-step（TEMP 快照
    task_links / task_deps / goals / task_attach → 建新表 → 拷数据 → DROP → 换名 →
    重建索引与触发器 → 回填关系表）。
