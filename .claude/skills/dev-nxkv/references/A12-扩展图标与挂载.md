# A12 · SOP · 扩展图标与挂载

> 命中信号：「给这个按钮/菜单项加个图标」「功能都在，看着不像一个应用」「图标不显示」「加一份 svg」。
> **降阶口径（先记住，不然一定做过头）**：图标是**开发期资产复用**，不是产品模块。
> 不加页面、不加路由、不加入口，界面里不出现「SVG / 图标 / 资产库」这些字样。
> 第一版做过 `#/svghub` 资产库页 + 侧栏入口，被明确否掉并已删除——别再走一遍。
>
> 探针与硬刷新规程 → `B05-前端面板地图.md`；资产目录说明 → `docs/svghub.md`。

## ① 前置（先拿事实）

```powershell
ls src/web/frontend/svghub/                                    # 目录：types + 五个分类 + index/icon/serialize
grep -rn "name: '" src/web/frontend/svghub/catalog-act.ts | head -30    # 现有资产名（换 catalog-*.ts 看别的分类）
grep -rn "icon: '" src/web/frontend/components/tool-acts/modules.ts | head -20   # 哪些模块项已挂图标
grep -rn "<Icon" src/web/frontend --include=*.tsx | head -10   # 直接写 JSX 的少数几处
node --import tsx scripts/export-icons.mjs                     # 导出全库到 temp/icons/，顺带证明资产没写坏
```

资产名清单不要记数字（会变）：以 `grep "name: '"` 的输出为准。

## ② 判定：这是哪一种活

| 现象 | 该动 | 不该动 |
|---|---|---|
| 库里没有这个图形 | 在对应分类文件加一份资产 | 直接在组件里手写 `<path>` |
| 动作项 / 菜单项是纯文字 | `modules.ts` 对应表填 `icon` | 改渲染层（它已经会画） |
| 一整套新工具区/菜单没图标 | 改渲染层：`metaOf(kind,id).icon` + `<Icon/>` | 只给其中一处加 |
| 图标与文字贴太紧 | 容器 CSS 补 `gap` 与 `.ic` 配色 | 给图标加 `margin` 补丁 |
| 想要「图标总览页」 | **不做**（降阶） | 加面板/路由/入口 |

## ③ 动作（顺序固定，跳一步就会漏）

1. **先查重**：`grep -rn "label: '中文名'" src/web/frontend/svghub/`。能复用就复用，资产是共享的，不是每处一份。

2. **加资产**（`src/web/frontend/svghub/`，按分类挑文件）：

   | 分类 | 文件 | 放什么 |
   |---|---|---|
   | nav | `catalog-nav.ts` | 目录 / 任务 / 面板 / 展开折叠 |
   | repo | `catalog-repo.ts` | 开发仓库 / 参考仓库 / 组 / 分支 / 远程 |
   | doc | `catalog-doc.ts` | 文档 / 标签 / 附件 / fork |
   | state | `catalog-state.ts` | 完成 / 等待 / 警示 / 锁定 |
   | act | `catalog-act.ts` | 增删改 / 保存 / 导入 / 评论 / 快捷键 |

   一条资产 = `{ name, label, group, els }`，可选 `keys`（检索别名）、`where`（挂载点说明）、`w`、`size`。
   图形只用四个构造器：`p()` 描边路径、`f()` 填充路径、`c()` 圆、`r()` 矩形；坐标一律 24×24 网格，
   颜色跟文字走（`stroke=currentColor`），所以**不要**写死颜色。`name` 用小写字母/数字/连字符。

3. **挂载到模块表**：`src/web/frontend/components/tool-acts/modules.ts` 六张表（dir / group / task / doc / repos / repos-row）逐项补 `icon: 'name'`。
   顺带把标签里的字符前缀去掉（`＋ 新建页` → `新建页`），`＋` 交给 `plus` 图标——字符和图标同时出现会重一遍。

4. **渲染层四处都要看**（这一步最容易漏，本轮就漏了文档页）：

   | 面 | 文件 | 说明 |
   |---|---|---|
   | 目录/组/仓库页工具区与行内动作 | `src/web/frontend/components/tool-acts/bar.tsx` | 走 `metaOf(kind,id).icon` |
   | 任务页头 | `src/web/frontend/components/md/shell/tool-bar.tsx` | `KIND = 'task'` |
   | 文档页头 | `src/web/frontend/components/doc/doc-head.tsx` | `KIND = 'doc'`，**与任务页头是同构的两份实现** |
   | 编排面板 | `src/web/frontend/components/tool-acts/layout-panel.tsx` | chip 与行 |
   | 侧栏 | `src/web/frontend/components/sidebar/index.tsx` | `rowIcon()`：组=branch、仓库=cube、参考仓库=repo-ref、全局=globe |

   页面里需要单独画一处时用 `<Icon name="…" />`（`components/icons.tsx` 转出，自带 `.ic` 类）。

5. **补 CSS 只补容器**：`.btn`、`.mdw-fmt-menu-item`、`.ta-more-it` 已有 `gap`；
   新容器照抄 `.ta-more-it .ic { flex: none; color: var(--mid, #838A93) }` 与 hover 变 `currentColor` 两行即可。

6. **改完跑导出**：`node --import tsx scripts/export-icons.mjs`，产物在 `temp/icons/`（gitignore），能顺手看出图形是否空。

7. **文档**：资产目录口径与挂载点写进 `docs/svghub.md`（它是开发说明，不是产品文档）。

## ④ 自检

```powershell
pnpm typecheck
pnpm build
node --import tsx --test tests/unit/svghub-catalog.test.mjs    # 资产合法 + 挂载守护（名字写错会红）
node --import tsx --test tests/unit/tool-acts-modules.test.mjs # 工具区按钮序列（加/删项要同步）
```

浏览器目视（**必须硬刷新**，见失败分支第 1 条）：目录页/组页/仓库页工具区 + 更多、任务页更多、文档页更多、侧栏行。

| 检查 | 通过判据 |
|---|---|
| 名字没悬空 | `svghub-catalog` 的挂载断言全绿（`<Icon name>`、`glyph()`、`icon: '…'` 三种写法都扫） |
| 该出现的地方都出现 | 上述四个面每一层菜单项前都有图形，不是只有工具栏那一个 |
| 不抢文字 | 图标与标签间距均匀；标签里没有残留 `＋` `⋯` 这类字符前缀 |
| 概念不外泄 | 界面文案里没有「SVG / 图标 / 资产」字样，也没有新页面/入口 |
| 没画死颜色 | 资产里没有 `#` 色值；深浅主题切换后图标跟着文字变 |

## ⑤ 失败分支

| 症状 | 原因 | 处置 |
|---|---|---|
| 改完页面还是纯文字 | 浏览器在跑旧 bundle：只改 hash **不会重载** | URL 加 `?cb=1`（如 `http://127.0.0.1:7900/?cb=1#/doc?ref=…`）再进；必要时重启 serve |
| 某处图标空着但代码写了 | 资产名不存在——`SvgIcon` 查不到就 `return null`，静默变白 | 跑 `svghub-catalog` 的挂载断言，它会点名「哪个名字 @ 哪个文件」 |
| 任务页有图标、文档页没有 | 两份同构页头只改了一份 | 两处都改（`md/tool-bar.tsx` + `doc/doc-head.tsx`） |
| 图标挤成一团 / 离文字太近 | 容器没 `gap` | 按第 5 步只补容器 CSS，别给图标加 margin |
| 深色/浅色主题下图标看不见 | 资产里写死了颜色或用了 `fill` 实心色 | 改回 `stroke=currentColor`，颜色留 CSS |
| 直接跑 `tsc` / `vite` 报 `Command "tsc" not found` | `node_modules/.bin` 缺失（环境重装中） | 直接 `node node_modules\typescript\bin\tsc -b tsconfig.web.json`、`node node_modules\vite\bin\vite.js build` |
| 单测里 `docs-transfer` / 迁移类用例红 | `main@83732c4` 自身遗留（已用 stash 复跑确认） | 与本 SOP 无关；只认 `svghub-catalog` 与 `tool-acts-modules` 两处 |

## ⑥ 反模式

- 为了「展示图标」加页面 / 面板 / 路由 / 侧栏入口——已被否掉一次。
- 界面文案、按钮、菜单里出现「SVG」「图标资产」「图标库」。
- 组件里手写 `<svg><path …/></svg>`，不入库：下次改线宽要全仓搜。
- 只改一个渲染面就宣布完成（四处渲染层 + 侧栏，逐一过）。
- 为了对齐去改图标尺寸/写死 `width`：尺寸由调用方给（默认 14，侧栏 15），网格内改图形才对。
- 把 `temp/icons/` 的导出物提交进仓库。
