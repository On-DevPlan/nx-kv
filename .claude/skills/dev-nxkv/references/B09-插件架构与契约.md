# B09 · 插件（pretask）架构与契约

> 一句话边界：**插件包自注册，宿主只做生命周期与调用**。
> 插件 = `packages/plugin-<id>/`（server 清单 + client `registerPlugin` + 自有表）；
> 宿主 = `src/modules/plugin/`，只负责发现、启用/停用、迁移版本、入口聚合、可见性/默认项、RPC 分派与页面挂载。
> 插件只允许依赖 `@nx-kv/plugin-sdk` + React，**不许 import 宿主 `src`，不许写宿主表**。

查它用这几条命令：

```powershell
node bin/kv.mjs plugin list --json
node bin/kv.mjs plugin entries --topic <topicKey> --json
node bin/kv.mjs plugin context --topicKey <topicKey> --json
node bin/kv.mjs plugin visibility --scopeKey topic:<topicKey> --json
grep -n "nxkv" packages/*/package.json
grep -rn "registerPlugin" packages/*/src/client/index.tsx
```

## 包发现与自注册

| 层 | 位置 | 职责 |
|---|---|---|
| 插件清单 | `packages/*/package.json` 的 `nxkv` 字段 | 唯一自注册声明：`api` / `server` / `client` / `style` |
| 生成 | `scripts/gen-plugins.mjs` → `src/modules/plugin/plugins.generated.ts` | 生成 `{ name, dir }`，`dir` 是**相对包根**的目录（不写绝对路径） |
| 加载 | `src/modules/plugin/registry.ts` | 按包根相对目录读 package.json → import server 产物（**不走 node_modules 包解析**） |
| 资产 | 插件包的 `dist/client/*` | 宿主按 `/plugins/<id>/client.js`、`/style.css` 输出 |
| 构建 | `scripts/build-plugins.mjs` | 扫清单：server 先 tsc 类型检查、再由 Vite 打成**单文件**（SDK 内联）；client 打 IIFE |
| 门禁 | `scripts/check-plugin-isolation.mjs` | 清单一致、双向 import 闭合、路径不出包 |

`nxkv.server` 必填；声明 `client` 就必须有 `vite.config.ts`，声明 `server` 就必须有 `tsconfig.server.json`。

**内置发布**（`npx nx-kv` 直接可用）：

| 规则 | 原因 |
|---|---|
| 插件包 `private: true` | 不单独发 npm，随宿主包分发 |
| 根 `dependencies` 不含任何 `@nx-kv/*` | 安装后不解析 workspace 包；插件 server 已内联 SDK |
| 根 `devDependencies` 保留 `@nx-kv/plugin-sdk: workspace:*` | 仅类型检查与前端构建用 |
| 根 `files` 必须包含 `packages/` | 插件 `package.json + dist` 随 tarball 发布 |
| 根 `dependencies` 必须有 `tsx` | `bin/kv.mjs` 运行时用 tsx 直接执行 TS 源码 |

## 服务端契约（`definePlugin`）

| 字段 | 语义 |
|---|---|
| `id` | 插件 id（不含 `:` / `.`）；入口 id 必须是 `<id>:<localId>` |
| `version` / `api` | 插件版本；API 版本固定 `^1` |
| `name` / `description` / `order` | 设置页与下拉分组展示 |
| `defaultEnabled` | 缺 `plugin_state` 行时的全局默认开关 |
| `entries(ctx)` | 当前 scope 的入口列表；拿不到定位可返回 `[]` |
| `buildDraft(ctx, entryId, values)` | 只服务 `kind='draft'`；`panel` 入口不要走这里 |
| `rpc` | `{ [method]: (ctx, params) => Promise<any> }`，方法名只允许 `[A-Za-z][\w]*` |
| `storageVersion` / `migrateStorage(db, from)` | 插件自有表结构；宿主只记 `plugin_storage_migrations` 版本号 |
| `migrateLegacy(ctx, kind, payload)` | 一次性旧数据导入；成功后宿主删除暂存行 |

## 入口模型（`EntryView`）

| 字段 | 说明 |
|---|---|
| `id` | `<pluginId>:<localId>`，稳定、不复用 |
| `label` / `description` / `icon` | 下拉与配置页展示 |
| `kind` | `draft`（生成正文）或 `panel`（打开插件页面） |
| `order` | 同 scope 下的排序基数（可被用户排序覆盖） |
| `default` | 插件级默认（**只作旁观回落**，下拉里不再标「默认」） |
| `builtin` | 内置入口徽标 |
| `slots` / `previewBody` / `values` | 无 form 的 draft 由宿主渲染预览并填值 |
| `ui.row` | 下拉行组件（插件自带）；否则用 `label/icon` |
| `ui.form` | draft 入口的参数页（进插件页面） |
| `ui.panel` + `panel.title` | panel 入口打开的页面 |

默认入口解析优先级（宿主 `listEntries`）：**本 scope 显式配置** → 可见的插件声明 `default` → 第一个可见草稿 → 第一个可见入口。

## 客户端契约（`registerPlugin(id, def)`）

| 字段 | 说明 |
|---|---|
| `api` | 必须 `^1` |
| `components` | 组件表：`ui.row` / `ui.form` / `ui.panel` / 侧栏页面都从这里取 |
| `pages` | `{ [pageId]: { title } }`；路由 `#/plugin/<id>/<pageId>[/<sessionId>]` |
| `sidebar` | 自注册左下角条目：`{ id,label,icon,order,page }` |

宿主注入的 `PluginClientApi`：

| 能力 | 说明 |
|---|---|
| `ctx` | 当前 `PretaskContext`（topic / location / 扁平定位字段） |
| `entry` | 仅入口页面有 |
| `rpc(method, params)` | 调插件自己的 server RPC（自动带 ctx） |
| `host.get(path, params)` | 只允许 `/api/`：`/api/plugins/context`、`/api/plugins/tree`、`/api/plugins/file`、`/api/repos`… |
| `draft(entryId, values)` | 取插件草稿正文 |
| `createDraft({ body,title }, { submit?, project?, board? })` | 落草稿并开任务页；组场景可覆盖归属 |
| `navigate` / `closePage` / `toast` | 宿主导航、关页、提示 |

React 由宿主共享（`window.NxkvReact` 等），插件包把 React 声明为 peer，不进 bundle。

## 上下文（`PretaskContext`）

| 字段 | 来源 / 口径 |
|---|---|
| `topicKey` / `groupKey` / `repoKey` / `cwd` | 扁平定位；插件页 session 透传 |
| `topic` | 宿主按 DB 补全的 `{ key,name,kind,cwd,repoKey,groupKey,repoName,groupName,repoRoot }` |
| `location` | `{ dirKey, groupId, board, project, taskId }` |
| `kind` | 前端显式声明的页面性质优先（目录页=repo / 组页=group）；未声明时才按 DB 推 |

## 宿主 HTTP 能力（给插件补齐缺失信息）

| 接口 | 关键参数 | 边界 |
|---|---|---|
| `GET /api/plugins/context` | `topicKey` / `groupKey` / `repoKey` / `cwd` | 只读；返回 topic/repo/group/组内 repos |
| `GET /api/plugins/tree` | `repoKey`、`path`、`showHidden` | 只认已登记 `type='repo'`；拒软链/重目录；最多 500 项 |
| `GET /api/plugins/file` | `repoKey`、`path`、`maxBytes` | realpath 必须留在 repo 根内；默认 256KB / 上限 1MB；二进制不回正文 |

## 生命周期与存储

| 表 | 归属 | 语义 |
|---|---|---|
| `plugin_state` | 宿主 | 全局启用/停用（设置页「插件」分区） |
| `plugin_storage_migrations` | 宿主 | 插件自有表结构版本账本 |
| `plugin_legacy_data` | 宿主 | 旧内置能力交接暂存（按 `(plugin_id, kind)`） |
| `plugin_entry_visibility` | 宿主 | 按 scope（`topic:` / `repo:` / `group:`）的可见性、顺序、`is_default` |
| `plugin_<id>_*` | **插件** | 业务数据；宿主不认识列，也不写 |

「新建页行为」= scope 级配置：可见性 + 默认入口（`plugin.set-default`）。
默认项被隐藏时不生效但保留配置；`plugin set-visibility` 不动默认项。

## 红线（违反即 lint 失败）

- 插件源码只能 import：包内相对路径 / `node:` / `@nx-kv/plugin-sdk` / `react(-dom)`。
- 宿主 `src` 不得 import 插件包，也不得硬编码插件包名（`plugins.generated.ts` 除外）。
- 宿主运行时不得依赖 `@nx-kv/*`：SDK 只在构建期（devDependencies）与插件 server 打包时使用。
- 插件 `dependencies` 只能有 SDK；React 只做 peer；插件包必须 `private: true`。
- 插件表名以 `plugin_` 开头、由插件自己的 `migrateStorage` 建；不许读写 `tasks/topics/repos/docs/settings`。
- 不要把插件专属 UI/文案写进宿主：宿主只给通用挂载点与生命周期配置。
