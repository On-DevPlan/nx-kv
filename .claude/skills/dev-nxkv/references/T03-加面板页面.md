# T03 · 加面板页面 / 改前端交互

> 前端只有一条硬线：**页面不 import 后端，只走 `/api`**；地址与面板必须**逐字互逆**。

## ① 前置（先跑，拿事实）

```powershell
ls src/web/frontend/page/                       # 现有页面目录
cat src/web/frontend/routes/templates.ts        # 一个完整的 definePage 范例（含三种 mode）
sed -n '20,60p' src/web/frontend/routes/types.ts   # RoutePage / RouteReverse 契约
grep -n "VIEWS" -A 15 src/web/frontend/registry.ts
grep -n "PANELS" -A 25 src/web/frontend/panels.tsx

ls src/web/frontend/page/repos/ && cat src/web/frontend/page/repos/api.ts | head -20
```

## ② 动作：一个页面 = 一个目录 + 四处登记

**1. 建目录** `src/web/frontend/page/<name>/`

```
index.jsx      # 页面组件（默认导出）
api.ts         # 本页的 /api 调用，具名函数；页面只 import 这里
```

`api.ts` 形状（页面函数不许裸调 `api()`）：

```ts
import { api } from '../../api/client.js';

export function fetchXxx(id: string) {
  return api<{ ok: boolean; data: XxxRow }>(`/api/xxx/${encodeURIComponent(id)}`);
}
```

**2. 登记视图** `src/web/frontend/registry.ts`：

```ts
{ id: '<name>', module: '<后端域>', component: lazy(() => import('./page/<name>/index.jsx')) },
```

`module` 只用于静态自检（`registry.test.mjs` 校验归属不悬空），**不是**后端引用。

**3. 登记面板** `src/web/frontend/panels.tsx` 的 `PANELS`：

```ts
'<name>': { title: '页签名', render: (cfg, ctx) => <XxxPanelView ... /> },
```

`component` 名要与路由文件里 `panel.component` **逐字一致**。

**4. 登记路由** `src/web/frontend/routes/<name>.ts` + `routes/index.ts`：

```ts
export const xxxPage = definePage({
  view: '<name>',                                  // hash 一级段： #/<name>/…
  panelOf: (route, _ctx) => {
    if (route.mode === 'edit' && route.id) {
      return { panel: { component: '<name>', config: { mode: 'edit', id: String(route.id) } }, name: '编辑…' };
    }
    return { panel: { component: '<name>', config: {} }, name: '…' };
  },
  reverse: [{
    component: '<name>',
    order: 0,
    format: (cfg) => {
      // ★ 必须能把 panelOf 生成的 config **逐字**变回地址
      if (cfg.mode === 'edit' && cfg.id) return `#/<name>/edit/${encodeURIComponent(cfg.id)}`;
      return '#/<name>';
    },
  }],
});
```

再在 `routes/index.ts` 的 `PAGES` 里加一行。

**5. 接线后端**：要的接口不存在 → 回 `T01` 加 action；前端只能调已存在的 `/api` 路径（`registry.test.mjs` 会核对）。

## ③ 自检

```powershell
pnpm typecheck
pnpm build
node --import tsx --test tests/unit/route-table.test.mjs tests/unit/frontend-refs.test.mjs tests/unit/registry.test.mjs
```

| 检查 | 通过判据 |
|---|---|
| 双向可逆 | 打开页面 → 复制地址 → 刷新，仍落在同一块面板、同一形态 |
| 页签不裂 | 切页/切面板多次，页签数量不增加 |
| 归属不悬空 | `registry.test.mjs` 通过（view 的 module 存在、`/api` 字面量有路由） |
| 真机走查 | `pnpm build` 后开 `nx-kv serve`，带 `?cb=1` 访问（避免缓存误判） |

交互复杂的页面（菜单、快捷键、拖拽）建议用隔离探针：独立 `NX_KV_LOCALTASK_STORE` + 临时端口 + Playwright，绝不碰真实队列。

## ④ 失败分支

| 症状 | 原因 | 处置 |
|---|---|---|
| 同一页面裂出两个页签 | `panelOf` 生成的 config 与 `reverse` 写回的 hash 不等价 | 让 `format(panelOf(route).panel.config) === 原 hash`，逐字对齐 |
| 刷新后跳到空页 | 编辑/新建的 `mode` 没写进地址 | 照 `routes/templates.ts` 的 `#137` 注释：mode 必须进 hash |
| 点按钮改完不生效 | 只改了源码没构建 | `pnpm build` 后重启 serve；浏览器带 `?cb=1` |
| 页面上 `api()` 报 eslint | 页面裸调 | 挪进 `page/<name>/api.ts` |
| 新面板内容不刷新 | FlexLayout 的 `TabContentRenderer` 是 `React.memo`，只认 tabNode 身份与 redraw revision | 别靠 `updateNodeAttributes` 换 config；参考 `panels.tsx` 里 `PanelHost` 的 `configSig` 订阅 |
| 面板里 `querySelector` 抓错块 | 同页多块 `.mdw` | 探针逐场景清 `localStorage('nx-kv-ui.workspace')` 并 reload，断言全量扫描 |

## ⑤ 反模式

- 为一个按钮再写一套表单（先找现有 section / 编辑器组件复用）。
- 把「任务模板」和「提示词区块模板」塞进同一个表单（两者是不同表、不同语义）。
- 在 `reverse` 里返回 `undefined` 表示「不改地址」以外的东西——`undefined` = 不归本视图，`null` = 归但不改地址。
