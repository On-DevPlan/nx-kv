# 任务模板整套流程（#130–#132）

## 一句话

模板是**资源**；`scope` 是平级绑定（`*` / `topic:` / `repo:` / `group:`），不是「默认全局再例外」。
选用 = 把正文**复制**进新建任务。

## 职责拆分

| 入口 | 做什么 |
| --- | --- |
| 设置 → 任务模板 | **只管可见绑定**（左列表 + 右 chips） |
| 工作区 `#/templates` | **改正文** / 增删 / 设默认 |
| 目录「模板 ▾」 | 就地新建 → 自动 `topic:<本目录>` |
| 组页「＋ 新增任务 ▾」 | 点击下拉（portal+fixed）；就地新建 → 自动 `group:<本组>` |

## 可见判定

三把钥匙 + `*` 平级命中即可用。组是独立可见主体（可只传 `?group=`）。
