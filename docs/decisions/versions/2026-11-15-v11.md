# 2026-11-15 · 存储版本 11 说明

- date: 2026-11-15
- version: 11
- migration: `src/core/db/migrations/v11.sql`（纯 DDL）+ `v11-data.ts`（存量孤儿起算时间回填）
- tables: `refs`（新增 `orphan_since`）、`ref_gc_log`（新增）
- changes:
  - `refs.orphan_since`：无任何 `ref_bindings` 归属的失绑起算时间（毫秒；0 = 未计时）。
    由「有归属」变「无归属」时写入当前时刻；重建索引不刷新已在计时中的孤儿。
  - 存量孤儿在升级时统一把起算时间置为迁移时刻，保证升级后仍有完整 TTL 缓冲。
  - `ref_gc_log`：孤儿到期清理的不可变留痕（ref_id / desc / origin / body_bytes /
    unbound_at / deleted_at / ttl_days / reason / source / snapshot）。
  - 到期清理为**软删**（`refs.deleted_at`），保留 `ref_bodies`；只清理空正文孤儿，
    有正文的到期孤儿只列清单、不自动删。
  - 新增设置项 `app.orphanTtlDays`（默认 3 天）、CLI `docs orphans` /
    `docs orphans purge`、serve 每小时例行维护、设置面板「文档清理」。
- notes:
  - 升级前自动 `VACUUM INTO` 备份（既有迁移管线行为不变）。
  - 数据回填不修改 `updated_at`，避免打乱文档列表的最近更新排序。
  - 决策见 `docs/decisions/2026-11-15-orphan-ref-gc.md`。
