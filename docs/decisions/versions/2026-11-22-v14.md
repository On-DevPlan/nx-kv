## changes

- **`task_links.type` 新增 `fork`**：任务链节点四类可辨——并行评论（comment）、
  返工反馈（feedback / reopen）、分支复制（fork）。
- 旧约束只有 comment / reopen / feedback，fork 只能被记成 comment（「复制一份另起分支」
  与「一条批注」分不清）。用户场景（#177）：一个任务下同时看到两个评论、一个反馈、
  一个 fork 四个同级子节点。
- `src_id → dst_id` 方向（新→旧）与一父唯一索引 `ux_task_links_parent` 不变——
  树仍是树（每任务至多一个来源），后代可任意分叉。
