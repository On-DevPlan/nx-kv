# 2026-11-13 · 存储版本 8 说明

- date: 2026-11-13
- version: 8
- migration: `src/core/db/migrations/v8.sql` + `v8-data.ts`（DDL + 一次性数据搬运）
- tables: 改 `refs`（删除 `rel`）、`ref_bindings`（新增 `tag`）
- changes:
  - **删除 `refs.rel`**：ref 的地址只有 `id`（DB 身份）与 `locator`（外部文件/URL 的
    实际位置）。历史文档树路径一次性迁移到 `locator`，运行时不再按路径找文档。
  - `ref_bindings.tag`：原 `docLinks` 条目的分类标签落库；`ref_bindings` 仍是宿主
    文档集的索引（`repo` / `group` / `group_repo`，position=0 为主篇）。
  - 宿主 ext（`repo.doc` / `repo.docLinks` / `board.doc` / `board.docLinks` /
    `board.repoDocs`）里的 `DocRef{rel|path}` 全部迁成 `DocRef{ref: refId}`；
    外部路径先登记成 `origin='external'` 的 ref，位置写 `locator`。
  - 历史「约定路径」文档（`repo/<key>/index.md`、`board/<组>/index.md`、
    `group/<组>/<key>.md` 等）在迁移时解析成**显式 ref 绑定**；运行时不存在
    默认路径回落。原字符串描述（`repos.description` / 组 desc / 成员 note）
    若还没有对应文档，迁移生成直接 ref 承接正文。
  - v7 面板新建、只写在 `ref_bindings` 的直接归属，迁移时反向补进宿主 ext，
    保证「ext 为语义、ref_bindings 为索引」两层一致。
  - `docId` 统一 `ref:<refId>`；`path:` 只用于外部目录里的裸文件（不是 ref）。
  - 导入导出格式升到 v5：zip 内 `docs/<refId>.md`，`layout.refs` 记录
    `{refId, origin, locator, desc}`；不再有 rel / 约定路径。
  - **显示名补一层兜底**：路径删除后文档没有「文件名」了，显示名改为
    正文首行 `# 标题` → `desc` → 正文首行摘要 → `locator` 末段 → refId，
    否则没有 `# 标题` 的旧文档在界面上会全叫「未命名文档」。
  - **`refs.body_bytes` 改为随正文同步**（此前只有迁移脚本写过一次，
    写正文 / 导入之后列表页的「大小」长期失真）。列本身保留：
    它是正文大小的缓存列，列表查询读它就不必拖着正文跑。
- 兼容：不做运行时兼容。旧程序无法读 v8 库；升级前由启动检查自动备份
  `~/.nx-kv/backups/nxkv-v7-<时间戳>.db`。
- 回滚：只允许向前升级；需要旧结构时用备份库恢复。
