# 任务 #87「ui优化」施工单（nx-kv）

> 任务来自 nx 组队列（nx-kv #87），两张截图：组页头部 + 设置里的「槽位内容」弹窗。

## 需求解读
1. **组页头部**：组简介那段文字被右侧动作按钮压住一半 → **不展示简介文本**（组介绍已是文档，「组介绍」入口直达）。
2. **设置「任务模板」页签**：截图是「槽位内容 · 默认模板」编辑器 → **删掉它，直接文字就是模板**。

## 改动
| 面 | 动作 |
|----|------|
| 组页头部 | 删 `{board.desc}` 段落；`.rp-group-acts` 由 `position:absolute` 改为静态流内右对齐（标题再长也不被压） |
| 设置 · 任务模板 | 「槽位内容 · 默认模板」+ 槽位编辑器 → 「模板正文 · 默认模板」+ 复用 TemplateEditor 直接改正文（草稿初始 = 渲染后的文字） |
| 模板面板 | 删「填槽位」入口与展开区；内置模板也放开「编辑」；列表预览显示渲染后的文字 |
| 出厂文本 | `NEWTASK_BODY` / `NEW_TEMPLATE` 改为**内联文字**（不再留 `{{槽位}}`；渲染结果逐字不变） |
| 兼容 | 老模板 body 里的 `{{槽位}}` 仍按 values 渲染（`renderTemplateBody`），界面不再暴露槽位概念 |
| 顺带修 bug | ① `PATCH /api/templates/default` 被「设默认」字面量路由截走 → **面板里改默认模板一直 400**（字面量路由优先于 `:id`）：该路由按载荷分派（带 body/name/values = 改默认模板，只带 id = 设默认），前端 update 带 id<br>② 目录页「模板 ▾」选非默认模板时用**原始 body** → 裸 `{{槽位}}` 进任务正文；改为按取值渲染 |
