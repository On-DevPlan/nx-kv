# C02 · 前端 · 改交互 / 组件 / 样式

> 序列 C（前端）。页面与登记点都已在位，只改「点下去发生什么」：状态、快捷键、异步守卫、复用组件、样式。
> 新增一个页面 → 用 `C01-加面板页面.md`。

## ① 前置（先跑，拿事实）

```powershell
grep -rn "<按钮文案 / 函数名>" src/web/frontend --include=*.tsx --include=*.ts | head -20   # 先定位到文件
ls src/web/frontend/components/                                # 可复用的组件目录
grep -n "^export" src/web/frontend/components/ui.tsx            # Copyable / ErrorBoundary / DiffPre …
grep -n "^export" src/web/frontend/components/toast/index.tsx   # useToast / useGuard
grep -n "^export" src/web/frontend/workspace.ts                 # 面板开关 / config 工具
grep -n "useApp" src/web/frontend/app-context.tsx | head -5     # 导航与全局刷新
```

## ② 先判定：改哪一类

| 改动性质 | 落在 | 备注 |
|---|---|---|
| 一个按钮/一处交互的行为 | `page/<name>/index.jsx` 或该页拆出的 `*.ts` | 逻辑别写进 JSX 里 |
| 多处要用的展示件 | `src/web/frontend/components/<域>/` | 先搜有没有同款，别新建 |
| 面板开/关、跳到某地址 | `src/web/frontend/workspace.ts` / `app-context.tsx` 的 `useApp()` | 不要自己拼 hash 再 `location.href` |
| 文案与布局 | `styles-v2/*.css`（对应域文件） | `style-v2.css` 只是 `@import` 聚合，别往里堆规则 |
| 面板 config 变化后内容不刷新 | `panels.tsx` 的 `PanelHost`（`configSig` 订阅） | 已有机制，别另造一套 |

## ③ 动作

1. **复用优先**：先看 `components/` 有没有同款（`toast` / `popup` / `task-panel` / `ui.tsx`），没有再新建。同一个交互两份实现，下次只改一边就会不一致。

2. **hook 顺序不可破坏**：任何早退（`if (!data) return …`）都必须写在**所有 hook 之后**——否则 React 抛 `Rendered more hooks than previous render`（#310），表现为白屏。

3. **文档级快捷键**改 `src/web/frontend/components/md/doc-keys.ts`，不要在各页面各写一遍：

```powershell
grep -n "docComboOf\|createComboGate\|COMBO_GAP_MS" src/web/frontend/components/md/doc-keys.ts
```

判定函数必须挡三类噪声：`e.repeat`（按住）、`e.isComposing || e.keyCode === 229`（输入法）、`altKey`；命中后 `preventDefault()`，再经节流闸门放行。

4. **异步动作加在途守卫**：`useGuard()`（`components/toast`）或一个 `ref` 标记，防止连点/连按产生多次请求（#189 的 Ctrl+S 就是这么抖出 20 次 PATCH 的）。

5. **反馈统一走 toast**：`useToast()`；同文案重复触发应原地续时而不是压新节点（栈上限 3 条）。

6. **跳转用 `useApp().onNavigate`**：主布局里是就地导航（保留面板），浮窗/旁路才关页签——直接 `deleteTab` 会把用户正在用的主面板拆掉（#191）。

7. **样式加在对应域文件**：

```powershell
ls src/web/frontend/styles-v2/        # shell / sidebar / dir / views / dag
grep -rn "nx-crumb" src/web/frontend/styles-v2/*.css | head    # 例：面包屑规则在 dag.css
```

## ④ 自检

```powershell
pnpm typecheck
pnpm build
node --import tsx --test tests/unit/<相关>.test.mjs
```

| 检查 | 通过判据 |
|---|---|
| 交互可达 | `pnpm build` 后开 serve，带 `?cb=1` 走一遍；零 `pageerror` |
| 不重复提交 | 连点/连按 5 次 → 只发 1 次请求，只出 1 条 toast |
| 面板不被拆 | 操作前后主布局页签数不变 |
| 样式命中 | 改的规则在 `styles-v2/<域>.css` 里；`style-v2.css` 仍只有 `@import` |
| 无回归 | 相邻按钮/快捷键仍可用（逐个点一遍） |

复杂交互用隔离探针（面板行为的唯一可靠证据）：

```powershell
# 独立数据目录 + 临时端口，绝不碰真实队列
$env:NX_KV_HOME="<repo>/temp/home-probe"
node bin/kv.mjs serve --port 7879 --no-open
```

探针里菜单项点不动用 `dispatchEvent('click')`；contentEditable 用 `click` + `Control+A` + `keyboard.type`（`page.fill()` 不触发 React onChange）。细节见 `D03-排障.md`。

## ⑤ 失败分支

| 症状 | 原因 | 处置 |
|---|---|---|
| 白屏 + `Rendered more hooks than previous render` | 早退写在了 hook 之前 | 把 return 挪到所有 hook 之后 |
| 按住快捷键触发几十次 | 没过滤 `e.repeat` / 没节流 | 走 `doc-keys.ts` 的 `docComboOf` + `createComboGate` |
| 中文输入时误触发 | 没判 `isComposing` / `keyCode 229` | 同上，判定函数已覆盖 |
| 面板 config 改了界面不变 | `TabContentRenderer` 是 `React.memo`，不看 config | 依赖 `PanelHost` 的 `configSig` 订阅；config 渲染时现读 |
| 点了两次发了两个请求 | 没有在途守卫 | `useGuard()` 或 `ref` 标记 |
| 删除后整个面板被拆掉 | 直接 `deleteTab` | 主布局改用 `onNavigate`，只在浮窗/旁路关页签 |
| 样式改了不生效 | 规则写在 `style-v2.css`（只做 `@import`）或被旧选择器覆盖 | 写进对应 `styles-v2/<域>.css`；`pnpm build` 后再看 |
| 浏览器里还是旧行为 | 加载的是旧 serve 实例 | 重启 serve；URL 带 `?cb=1` |

## ⑥ 反模式

- 在页面里写业务判断（该由后端算，前端只渲染）。
- 为一个小交互新建组件目录，而不复用 `components/` 里已有的。
- 用 `location.hash = …` 直接跳转，绕过路由的 `panelOf/reverse`。
- 把新规则堆进 `style-v2.css`（它是聚合入口，单文件行数也有门禁）。
